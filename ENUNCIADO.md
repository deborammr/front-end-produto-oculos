# Atividade 01 — Landing Page de Produto

Esta atividade valendo nota e poderá ser realizada individualmente ou em dupla.

Caso seja feita em dupla, os dois integrantes deverão realizar a entrega no Moodle para que a nota seja contabilizada para ambos.

Cada participante, individualmente ou em dupla, deverá inventar um produto fictício e desenvolver, utilizando React, um protótipo navegável de uma landing page para apresentar e vender essa ideia.

A aplicação será 100% client-side. Não é necessário backend, banco de dados ou integração com APIs. Todos os dados podem ser mockados.

## O que a página deve apresentar

- Identidade visual;
- Nome e proposta do produto;
- Hero section;
- Benefícios e diferenciais;
- Imagens ou representações do produto;
- Explicação de como funciona;
- Prova social ou avaliações fictícias;
- Oferta ou preço;
- FAQ;
- Pelo menos um CTA funcional ou simulado.

O CTA pode ser qualquer ação coerente com a proposta do produto, por exemplo: compra fictícia, download fake, formulário de cadastro, lista de espera, abertura de modal, navegação para outra seção etc.

Não haverá layout de referência.

A dupla deverá tomar suas próprias decisões sobre cores, tipografia, imagens, organização das informações, estilo visual, CTAs e experiência de navegação.

## Escolha do tema

O produto pode ser criativo, divertido, sério ou até mesmo nonsense. Entretanto, evitem propostas envolvendo temas sensíveis, conteúdo adulto, violência, drogas, política, discriminação, atividades ilegais ou qualquer conteúdo inadequado ao ambiente acadêmico.

## Repositório e entrega

O projeto deverá estar disponível em um repositório público no GitHub.

A entrega no Moodle será realizada enviando o link público do repositório.

## Arquitetura do projeto

Qual arquitetura foi escolhida para organizar o projeto?

A aplicação deverá utilizar uma das arquiteturas apresentadas em aula:

- MVVM
- FSD (Feature-Sliced Design)

## Desenvolvimento

O projeto deverá ser desenvolvido usando o React e CSS Modularizado.

Não é necessário utilizar padrões, bibliotecas, técnicas ou recursos que ainda não foram apresentados durante as aulas.
